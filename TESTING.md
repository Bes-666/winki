# Руководство по тестированию SkillStock

## 🔧 Настройка Telegram Webhook (ВАЖНО!)

Бот не будет работать, пока не настроен webhook. Выполните следующие шаги:

### Шаг 1: Получите URL вашего сайта на Netlify

1. Зайдите в Netlify Dashboard
2. Откройте ваш сайт
3. Скопируйте URL (например: `https://winki-123.netlify.app`)

### Шаг 2: Настройте Webhook

Откройте в браузере следующую ссылку (замените `YOUR_BOT_TOKEN` и `YOUR_NETLIFY_URL`):

```
https://api.telegram.org/botYOUR_BOT_TOKEN/setWebhook?url=https://YOUR_NETLIFY_URL.netlify.app/api/webhook
```

**Пример:**
```
https://api.telegram.org/bot7561238716:AAFa5_Ub7apYpni03jRCna2i7W9PXEVJfco/setWebhook?url=https://winki-123.netlify.app/api/webhook
```

### Шаг 3: Проверьте Webhook

Откройте в браузере:
```
https://api.telegram.org/botYOUR_BOT_TOKEN/getWebhookInfo
```

Должно показать:
```json
{
  "ok": true,
  "result": {
    "url": "https://your-site.netlify.app/api/webhook",
    "has_custom_certificate": false,
    "pending_update_count": 0
  }
}
```

## 🔍 Как проверить работу бота

### Если бот не отвечает:

1. **Проверьте webhook:**
   ```
   https://api.telegram.org/botYOUR_BOT_TOKEN/getWebhookInfo
   ```

2. **Проверьте логи Netlify:**
   - Site settings → Functions → Logs
   - Ищите ошибки при вызове `/api/webhook`

3. **Проверьте переменные окружения:**
   - Убедитесь, что `TELEGRAM_BOT_TOKEN` правильно установлен
   - Проверьте `SUPABASE_URL` и ключи

4. **Проверьте базу данных:**
   - Убедитесь, что SQL скрипт выполнен
   - Проверьте, что таблицы созданы

### Тестирование через браузер:

1. Откройте ваш сайт на Netlify
2. Проверьте все страницы
3. Попробуйте добавить навык через веб-интерфейс
4. Проверьте админ-панель
